## English

### Release status

**v1.0.11** is a previous stable Game Sync Hub release. The current Stable / Latest release is [v1.0.13](https://github.com/IMC93Labs/GameSyncHub-Releases/releases/tag/v1.0.13).

The published `GameSyncHub.exe` is the exact validated RC21 build.

- Size: `205,019,708` bytes
- SHA-256: `5d3dad4c2faf7147a1d88dc4d1974db9b8cc0416f39fa2ddb4bddc7a2e827777`

### Console Mode startup

This release finalizes the new Console Mode startup experience:

- Cinematic startup transition when automatic controller entry begins.
- Console Mode prepares behind the transition and is revealed only after the handoff is ready.
- Configured Console Mode ambient audio can start with the transition and continue into Console Mode without restarting.
- Intro multimedia playback is bundled with the portable application, avoiding a dependency on a separately installed media-player application.
- The public distribution remains a single self-contained `GameSyncHub.exe`.

### Updating

Existing installations can use the built-in updater. Official binaries and update metadata are published only through this repository's Releases.

### Arranque del Modo consola

Esta versión deja finalizada la nueva experiencia de entrada al Modo consola:

- Transición cinematográfica de inicio al comenzar la entrada automática mediante mando.
- El Modo consola se prepara detrás de la transición y solo se revela cuando el handoff está listo.
- El audio ambiente configurado del Modo consola puede comenzar junto con la transición y continuar después sin reiniciarse.
- La reproducción multimedia de la intro va incluida con la aplicación portable, evitando depender de una aplicación reproductora instalada por separado.
- La distribución pública continúa siendo un único `GameSyncHub.exe` self-contained.
