## English

### Overview

Game Sync Hub v1.0.15 is a reliability-focused release with major work on save synchronization, interrupted-operation recovery, controller hotplug stability and Console Mode polish.

The central goal of this release is to make cloud synchronization safer without turning Google Drive into a requirement for normal play. Local save data remains the primary working copy, while remote state is promoted only after the required verification steps complete.

### Save and cloud reliability

- Interrupted uploads and downloads can recover without promoting partial save data.
- Upload preparation uses immutable packages and verified hashes.
- Downloads are isolated in staging and verified before local promotion.
- Current / Previous history is preserved and checked before cloud state is advanced.
- Durable journals record critical recovery phases so an interrupted operation can be reconciled on the next start.
- Terminal states are monotonic: completed, superseded or blocked operations cannot be downgraded by stale asynchronous work.
- Save-set revisions use compare-and-swap protection so delayed background tasks cannot overwrite newer valid state.
- Startup recovery and the Repair flow share the same reconciliation rules.
- Multi-PC divergence is preserved as a conflict instead of automatically overwriting one branch.
- Safe obsolete staging can be cleaned automatically, while ambiguous recovery material remains protected.

### Google Drive performance

Reliability checks added during stabilization initially caused repeated remote-tree enumeration. v1.0.15 consolidates that work into an operation-scoped remote inventory while retaining an independent final verification before promotion.

Resumable upload chunks were also increased so typical save packages can be transmitted with fewer requests while retaining resumable-session semantics.

### Controller stability

A native WinMM/DirectInput HID hotplug path could terminate Game Sync Hub when a Bluetooth controller disconnected or reconnected. The affected capability-enumeration work is isolated so a native failure cannot bring down the main application process, while normal polling continues to use the lightweight state path.

### Console Mode and UX

This release also includes broad polish across the controller-first experience:

- refined Console Mode library and chrome;
- improved settings and game-editor presentation;
- multimedia preview/cache improvements;
- configurable subtle background motion;
- unified Graphite visual tokens and focus treatment;
- interface sound and haptic feedback calibration;
- refined startup intro and fullscreen handoff;
- accessibility and reduced-animation behaviour improvements.

### Validation

The final stable binary was validated with:

- **1379 / 1379** Release tests;
- **0 warnings / 0 errors** in the final Release build;
- repeated pre-upload process termination tests;
- durable-journal interruption tests;
- real upload interruption before, during and after remote transfer;
- real download/restore interruption across download and local commit phases;
- hash verification confirming intact save states rather than mixed partial states;
- multi-PC conflict tests;
- repeated restart/idempotency checks;
- real controller disconnect/reconnect validation;
- real-world save synchronization with controller and Console Mode transitions occurring while cloud work continued.

## Español

### Resumen

Game Sync Hub v1.0.15 es una versión centrada en fiabilidad, con un trabajo importante sobre sincronización de partidas, recuperación tras interrupciones, estabilidad del hotplug de mandos y pulido del Modo consola.

El objetivo principal de esta versión es hacer más segura la sincronización en la nube sin convertir Google Drive en un requisito para jugar normalmente. La partida local continúa siendo la copia de trabajo principal y el estado remoto solo se promociona después de completar las verificaciones necesarias.

### Seguridad de partidas y nube

- Las subidas y descargas interrumpidas pueden recuperarse sin promocionar datos parciales.
- La preparación de upload usa paquetes inmutables y hashes verificados.
- Las descargas se aíslan en staging y se verifican antes de promocionarse localmente.
- El historial Current / Previous se conserva y comprueba antes de avanzar el estado remoto.
- Journals durables registran las fases críticas de recuperación para poder reconciliar una operación tras reiniciar.
- Los estados terminales son monotónicos: una operación completada, superseded o bloqueada no puede degradarse por trabajo asíncrono obsoleto.
- Las revisiones de SaveSet usan protección compare-and-swap para impedir que tareas retrasadas sobrescriban estados válidos más recientes.
- Startup Recovery y Reparar comparten las mismas reglas de reconciliación.
- Una divergencia real entre varios PC se conserva como conflicto en lugar de sobrescribir automáticamente una rama.
- El staging obsoleto demostrado como seguro puede limpiarse automáticamente, mientras el material ambiguo permanece protegido.

### Rendimiento de Google Drive

Las comprobaciones de seguridad añadidas durante la estabilización llegaron a provocar enumeraciones repetidas del árbol remoto. v1.0.15 consolida ese trabajo en un inventario remoto reutilizable por operación, manteniendo una verificación final independiente antes de promocionar datos.

También se aumentó el tamaño de los chunks de las cargas resumibles para que los paquetes de saves habituales necesiten menos peticiones sin perder la semántica de sesión reanudable.

### Estabilidad del mando

Una ruta nativa WinMM/DirectInput relacionada con hotplug HID podía cerrar Game Sync Hub al desconectar o reconectar un mando Bluetooth. El trabajo de enumeración de capacidades afectado queda aislado para que un fallo nativo no pueda derribar el proceso principal, mientras el polling normal continúa usando la ruta ligera de estado.

### Modo consola y experiencia de uso

La versión incluye además un amplio pulido de la experiencia orientada a mando:

- biblioteca y chrome del Modo consola refinados;
- mejoras de presentación en ajustes y editor de juegos;
- mejoras de preview/cache multimedia;
- movimiento de fondo sutil y configurable;
- sistema visual Graphite unificado y tratamiento consistente del foco;
- calibración de sonidos de interfaz y háptica;
- intro de arranque y handoff fullscreen refinados;
- mejoras de accesibilidad y reducción de animaciones.
