## English

### Release status

**v1.0.13** is the current Stable / Latest Game Sync Hub release.

The published `GameSyncHub.exe` is the exact validated RC15 build.

- Size: `205,054,689` bytes
- SHA-256: `ca3a57c24116ce07de92e2b5a9d49b17c8602e932de2246ac8a2f2fa5f0590e3`
- Validation: `1095/1095` tests, Release build with `0 warnings / 0 errors`

### Performance and visual polish

v1.0.13 is primarily a refinement release focused on making Game Sync Hub feel faster, steadier and more finished without changing the established save/Drive behaviour.

- Reduced redundant initial refresh work and duplicate UI notifications.
- Preloaded and cached library images outside the first visible render path.
- Reduced provisional visual states so views are prepared before being revealed where practical.
- Improved startup, navigation and visual loading fluidity while preserving existing behaviour.

### Known save-path management

Create, edit and delete operations for known save paths now use a local-first flow:

- Persist the local change first.
- Update only the affected visible collection immediately.
- Synchronize the change with Google Drive in the background.
- Slow, offline or stale remote data no longer delays or visually reverts a confirmed local edit.

This changes the presentation/order of the operation, not the save-protection engine itself.

### Console Mode polish and controller stability

- Refined Console Mode window handoff to avoid intermediate legacy views, desktop flashes and first-restore glitches.
- Improved repeated Console Mode entry/exit lifecycle stability.
- Corrected native `JOYCAPS` marshalling used by the WinMM controller path, eliminating the heap-corruption crash identified during stress testing.
- Removed repeated logging caused by the obsolete `menu.wav` resource lookup while preserving the existing generated menu sound behaviour.

### Updates and release notes

- Concurrent update checks are coalesced into one request path.
- Update notes can be selected according to the current Game Sync Hub UI language (English/Spanish), with English fallback and backward-compatible manifest handling.
- Automatic and manual update checks continue to use the same verified updater path.

### Cleanup

- Definitively deleted legacy save profiles are excluded from periodic monitoring once they are no longer backed by an active junction.
- No broad save, Drive, junction, RTSS or controller-flow rewrite was performed as part of this optimization release.

### Updating

Existing installations can use the built-in updater. Official binaries and update metadata are published only through this repository's Releases.

## Español

### Estado de la versión

**v1.0.13** es la versión Stable / Latest actual de Game Sync Hub.

El `GameSyncHub.exe` publicado es exactamente la compilación RC15 validada.

- Tamaño: `205.054.689` bytes
- SHA-256: `ca3a57c24116ce07de92e2b5a9d49b17c8602e932de2246ac8a2f2fa5f0590e3`
- Validación: `1095/1095` tests, compilación Release con `0 warnings / 0 errors`

### Rendimiento y pulido visual

v1.0.13 es principalmente una versión de refinamiento orientada a que Game Sync Hub se sienta más rápida, estable y terminada sin cambiar el comportamiento ya consolidado de saves/Drive.

- Reducido el trabajo redundante del refresco inicial y las notificaciones duplicadas de UI.
- Precarga y caché de imágenes de la biblioteca fuera del primer render visible.
- Reducidos los estados visuales provisionales para preparar las vistas antes de revelarlas cuando es posible.
- Mejorada la fluidez del arranque, la navegación y la carga visual conservando el comportamiento existente.

### Gestión de rutas conocidas de partidas

Las operaciones de crear, editar y borrar rutas conocidas utilizan ahora un flujo local-first:

- Primero se persiste el cambio local.
- Se actualiza inmediatamente solo la colección visible afectada.
- El cambio se sincroniza con Google Drive en segundo plano.
- Un Drive lento/offline o datos remotos obsoletos ya no retrasan ni revierten visualmente una edición local confirmada.

Esto cambia la presentación/orden de la operación, no el motor de protección de partidas.

### Pulido del Modo consola y estabilidad del mando

- Refinado el handoff de ventanas del Modo consola para evitar vistas legacy intermedias, destellos del escritorio y fallos en la primera restauración.
- Mejorada la estabilidad del ciclo de entradas/salidas repetidas del Modo consola.
- Corregido el marshalling nativo de `JOYCAPS` utilizado por la ruta WinMM de mandos, eliminando el crash por corrupción de heap detectado durante las pruebas intensivas.
- Eliminado el logging repetitivo causado por la búsqueda obsoleta del recurso `menu.wav`, conservando el comportamiento actual del sonido de menú generado internamente.

### Actualizaciones y notas de versión

- Las comprobaciones simultáneas de actualización se agrupan en una única ruta de consulta.
- Las novedades de la actualización pueden seleccionarse según el idioma actual de la interfaz de Game Sync Hub (inglés/español), con fallback al inglés y manifest retrocompatible.
- Las comprobaciones automática y manual continúan utilizando el mismo actualizador verificado.

### Limpieza

- Los perfiles legacy eliminados definitivamente quedan fuera del monitor periódico cuando ya no están respaldados por un junction activo.
- Esta versión de optimización no realizó una reescritura general de saves, Drive, junctions, RTSS ni del flujo de mando.

### Actualización

Las instalaciones existentes pueden utilizar el actualizador integrado. Los binarios oficiales y los metadatos de actualización se publican únicamente mediante las Releases de este repositorio.
