## English

### Release status

**v1.0.12** is a previous stable Game Sync Hub release. The current Stable / Latest release is [v1.0.13](https://github.com/IMC93Labs/GameSyncHub-Releases/releases/tag/v1.0.13).

The published stable build follows the validated RC10 line.

- SHA-256: `3336e95e70da4870ab5097d635b03fc30b25d24e0c0a1f89c8d50bc1047a544c`

### Console experience polish

This release focuses on making the controller-driven Console Mode flow feel more complete and responsive:

- Xbox/XInput startup haptics use a short two-pulse pattern when Console Mode entry begins.
- The haptic sequence is non-blocking, safely cancelled on disconnect and always returns both motors to zero.
- Console Mode exit now uses a brief black `Exiting...` transition while the normal interface is restored behind it.
- The existing cinematic Console Mode startup transition, continuous ambience and self-contained media playback remain unchanged.

### Automatic update check

Game Sync Hub now performs one automatic stable-channel update check per app run after startup.

- The check runs in the background and does not block the main interface.
- It reuses the existing verified updater instead of introducing a parallel update path.
- When the application is already current, no unnecessary notification is shown.
- Temporary offline/network failures do not interrupt normal startup.

### Updating

Existing installations can use the built-in updater. Official binaries and update metadata are published only through this repository's Releases.

## Español

### Estado de la versión

**v1.0.12** es una versión estable anterior de Game Sync Hub. La versión Stable / Latest actual es [v1.0.13](https://github.com/IMC93Labs/GameSyncHub-Releases/releases/tag/v1.0.13).

La compilación estable publicada sigue la línea RC10 validada.

- SHA-256: `3336e95e70da4870ab5097d635b03fc30b25d24e0c0a1f89c8d50bc1047a544c`

### Pulido de la experiencia de consola

Esta versión se centra en hacer que el flujo de Modo consola con mando se sienta más completo y directo:

- La entrada con Xbox/XInput utiliza un patrón corto de dos vibraciones al comenzar el Modo consola.
- La secuencia de vibración es no bloqueante, se cancela de forma segura al desconectar el mando y siempre deja ambos motores a cero.
- La salida del Modo consola utiliza ahora una transición negra breve `Saliendo...` mientras la interfaz normal se restaura detrás.
- La transición cinematográfica de entrada, el audio ambiente continuo y la reproducción multimedia autocontenida existentes se mantienen sin cambios.

### Comprobación automática de actualizaciones

Game Sync Hub realiza ahora una comprobación automática del canal estable una vez por ejecución después del arranque.

- La comprobación se ejecuta en segundo plano y no bloquea la interfaz principal.
- Reutiliza el actualizador verificado existente en lugar de crear una ruta de actualización paralela.
- Cuando la aplicación ya está actualizada no muestra avisos innecesarios.
- Los fallos temporales de conexión o el modo offline no interrumpen el arranque normal.

### Actualización

Las instalaciones existentes pueden utilizar el actualizador integrado. Los binarios oficiales y los metadatos de actualización se publican únicamente mediante las Releases de este repositorio.
