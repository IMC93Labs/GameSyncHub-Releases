## English

Game Sync Hub v1.1.0 is a major architectural release focused on installed distribution, controller reliability, Console Mode integration and stronger save/cloud recovery.

### Highlights

- New installer-based public distribution.
- Future in-place updates use validated versioned Setup packages.
- Controller Virtualization improvements for Xbox-compatible controllers over Bluetooth and Xbox Wireless Adapter.
- Controller Device Broker + HidHide integration without per-game UAC prompts.
- Guide-button handling, Control Center access, haptic feedback and improved reconnect/session lifecycle.
- Stronger local-first save/cloud architecture with durable operations, recovery and multi-PC conflict protection.
- Improved Google Drive library reconstruction and metadata recovery.
- Improved Add Game and multimedia selection flow.
- Safer startup, shutdown, session and update lifecycle.
- Reproducible installer packaging with release provenance validation.

### Installation

Download `GameSyncHub-Setup-v1.1.0.exe` from the official GitHub Release and run the installer.

Users of previous v1.0.x portable builds should install v1.1.0 manually. Starting with v1.1.0, public releases use the installed application model.

### Updates

Future compatible stable releases can be installed through Game Sync Hub's built-in updater. The updater validates the stable release contract, exact Setup asset, size, SHA-256, SourceCommit and ProductVersion before installation handoff.

## Español

Game Sync Hub v1.1.0 es una actualización arquitectónica importante centrada en la distribución mediante instalador, la fiabilidad de los mandos, la integración del Modo consola y una recuperación Save/Cloud más robusta.

### Mejoras principales

- Nueva distribución pública mediante instalador.
- Las futuras actualizaciones sobre la instalación utilizan Setup versionados y validados.
- Mejoras de Controller Virtualization para mandos compatibles con Xbox por Bluetooth y Xbox Wireless Adapter.
- Integración de Controller Device Broker + HidHide sin avisos UAC al iniciar cada juego.
- Gestión del botón Guide, Centro de Control, respuesta háptica y mejor ciclo de reconexión/sesión.
- Arquitectura local-first Save/Cloud reforzada con operaciones durables, recuperación y protección frente a conflictos multi-PC.
- Mejor reconstrucción de biblioteca y metadatos desde Google Drive.
- Mejoras en Añadir juego y selección multimedia.
- Mayor seguridad en inicio, cierre, sesiones y actualizaciones.
- Empaquetado del instalador reproducible con validación de provenance de Release.

### Instalación

Descarga `GameSyncHub-Setup-v1.1.0.exe` desde la Release oficial de GitHub y ejecuta el instalador.
