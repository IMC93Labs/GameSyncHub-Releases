## English

### One place for your PC games

SYNCORE aims to bring together a Windows game library, a TV-friendly Console Mode, controller handling, artwork and game metadata, plus local-first save protection with Google Drive recovery.

### SYNCORE 2.0 — development status

The 2.0 work includes a redesigned SYNCORE identity and interface, more robust local/cloud save history, multi-PC verification, automatic recovery, and workflows to import previously backed-up saves. The imported-save activation workflow and final controller/dependency validation are still being completed. These features are **not yet a public 2.0 release**.

The final download, feature list, system requirements and release validation will be published only after acceptance testing.

### Current public release — Game Sync Hub v1.1.0

- Windows installer: [latest stable release](https://github.com/IMC93Labs/GameSyncHub-Releases/releases/latest).
- Download `GameSyncHub-Setup-v1.1.0.exe` and verify the optional `.sha256` file.
- The v1.1.0 installer and updater keep their historical names and contracts; do not rename the installer or `update.json` yourself.
- [v1.1.0 release notes](docs/releases/v1.1.0.md) are retained unchanged for accuracy.

### Project and support

This is the **official releases, documentation and support** repository; the application source code is not published here. SYNCORE is a personal, AI-assisted hobby project. Keep separate backups of important saves and test a new version with non-critical data first.

[Features and release distinctions](docs/guides/features.md) · [Support](SUPPORT.md) · [Security](SECURITY.md) · [Disclaimer](DISCLAIMER.md)

## Español

### Todos tus juegos de PC en un solo lugar

SYNCORE reúne biblioteca de juegos para Windows, Modo consola para televisión, mandos, portadas y metadatos, junto con protección local-first de partidas y recuperación mediante Google Drive.

### SYNCORE 2.0 — en desarrollo

El trabajo de la 2.0 incluye identidad e interfaz SYNCORE, historial local/cloud más robusto, verificación entre varios PC, recuperación automática e importación de partidas guardadas anteriormente. Todavía se están completando la activación de partidas importadas y las validaciones finales de mandos y dependencias. **Estas funciones no constituyen aún una versión pública 2.0.**

Publicaremos la descarga, las funciones definitivas, requisitos y resultados de validación una vez superadas las pruebas de aceptación.

### Versión pública actual — Game Sync Hub v1.1.0

- Instalador Windows: [última versión estable](https://github.com/IMC93Labs/GameSyncHub-Releases/releases/latest).
- Descarga `GameSyncHub-Setup-v1.1.0.exe` y comprueba el `.sha256` si lo deseas.
- El instalador y el actualizador de v1.1.0 mantienen sus nombres y contratos históricos; no cambies manualmente el nombre del Setup ni `update.json`.
- Las [notas de v1.1.0](docs/releases/v1.1.0.md) se conservan intactas.

### Proyecto y soporte

Este repositorio contiene **releases oficiales, documentación y soporte**; no publica el código fuente de la aplicación. SYNCORE es un proyecto personal realizado como hobby con ayuda de IA. Conserva siempre una copia independiente de las partidas importantes y prueba las nuevas versiones primero con datos no críticos.
